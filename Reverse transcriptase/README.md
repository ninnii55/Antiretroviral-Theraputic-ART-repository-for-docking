# Reverse transcriptase

This directory will contain reverse transcriptase structures, ligand files, and docking results for reverse transcriptase targets.
This range of drugs is broken up into two classes, Nucleoside Reverse Transcriptase Inhibitor (NRTI) and nonNucleoside Reverse Transcriptase Inhibitor (NNRTI). With the NRTI, they require phosporylation, known as the bioactive form therefore, this version of the compund will be available.
